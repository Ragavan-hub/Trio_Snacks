# Quick Start Guide — Trio Snacks

## 1. Install Dependencies
```bash
pip install -r requirements.txt
```

## 2. Start the Server
```bash
python app.py
```
*(Or run `./run.sh` on macOS/Linux, or `run.bat` on Windows)*

## 3. Access the Website & POS
- **Storefront**: `http://localhost:5000`
- **Admin Login**: `admin` / `admin123`
- **Cashier Login**: `cashier` / `cashier123`
